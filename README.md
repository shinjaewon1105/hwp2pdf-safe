# hwp2pdf-safe

한글(.hwp/.hwpx) 문서를 PDF로 바꾼다. 만든 PDF는

- 원본 한글 파일로 되살릴 수 있다.
- 본문을 긁어 복사해도 글자가 깨지지 않는다.
- 수식을 긁으면 `x = (-b±√(b²-4ac))/(2a)`처럼 읽을 수 있는 글로 복사된다. 모양은 한컴 PDF와 같다.

## 준비
- Windows, 한글 프로그램(한글 2024에서 시험함)
- Python 3, 그리고 `pip install -r requirements.txt`

## 쓰는 법
- **한글 → PDF**: 한글 파일을 `한글을 PDF로.bat` 위에 끌어다 놓는다. 같은 폴더에 PDF가 생긴다.
- **PDF → 한글**: 이 도구로 만든 PDF를 `PDF를 한글로.bat` 위에 끌어다 놓는다. 원본 한글 파일이 같은 폴더에 생긴다.
- 같은 이름의 파일이 있으면 덮어쓰지 않고 이름 뒤에 ` (2)`나 ` (복구)`를 붙인다.

명령줄로 쓸 때:
```
python hwp2pdf.py 보고서.hwp [-o 결과.pdf] [--eq unicode|latex|hwp] [--no-embed]
python pdf2hwp.py 보고서.pdf [-o 폴더]
```
- `--eq`: 수식을 복사했을 때 나오는 형식. `unicode`(기본), `latex`, `hwp`(한글 수식 스크립트) 중 하나.
- `--no-embed`: 원본 한글 파일을 넣지 않는다(아래 주의 참고).

## 꼭 알아 둘 것
- **PDF 안에 원본 한글 파일이 첨부된다.** PDF를 받은 사람은 누구나 첨부 파일을 꺼낼 수 있다. 메모, 숨은 글, 변경 내용도 같이 간다. 원본을 넘기면 안 되면 `--no-embed`로 만든다. 그러면 한글로 되살리기는 안 되고 복사만 된다.
- 한글로 되살리기는 이 도구로 만든 PDF에서만 된다. 다른 PDF는 못 바꾼다.
- 수식은 한 줄 글로 복사된다. 한글에 붙여 넣어도 수식 개체가 되지는 않는다.
- 옛한글은 크롬·엣지에서 복사하면 자모 순서가 바뀔 수 있다.
- 변환하는 동안 한글 프로그램이 화면에 안 보이게 뜬다. 원본 파일은 고치지 않는다.
- 변환이 끝나면 모양이 한컴 PDF와 같은지, 글자와 수식이 깨지지 않고 나오는지 검사 결과를 보여 준다.
