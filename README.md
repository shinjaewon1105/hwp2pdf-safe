# hwp-pdf: 되살릴 수 있고 글·수식이 안 깨지는 한글→PDF

## 쓰는 법
- **한글 → PDF**: `.hwp`/`.hwpx` 파일을 `한글을 PDF로.bat` 위에 끌어다 놓는다. 같은 폴더에 같은 이름의 PDF가 생긴다. 이름이 겹치면 덮어쓰지 않고 ` (2)`를 붙인다.
- **PDF → 한글**: 이 도구로 만든 PDF를 `PDF를 한글로.bat` 위에 끌어다 놓는다. 첨부해 둔 원본 한글 파일을 꺼낸다. 이름이 겹치면 ` (복구)`를 붙인다.
- 명령줄로 쓸 때:
  ```
  python hwp2pdf.py 보고서.hwp [-o 결과.pdf] [--eq unicode|latex|hwp] [--no-embed]
  python pdf2hwp.py 보고서.pdf [-o 폴더] [--open]
  python selftest.py        # 시험 문서를 만들어 변환·복구까지 확인
  ```
- `--eq`는 수식을 긁었을 때 나오는 글의 형식이다.
  - `unicode`(기본): `x = (-b±√(b²-4ac))/(2a)`
  - `latex`: `x=\frac{-b\pm\sqrt{b^{2}-4ac}}{2a}`
  - `hwp`: 한글 수식 스크립트 그대로

## 무엇을 하나
1. **복구**: 원본 한글 파일을 PDF 안에 그대로 첨부한다(PDF/A-3 '원본 파일' 방식). 꺼낸 파일은 SHA-256으로 원본과 바이트가 같은지 확인한다. 그래서 수식, 표, 메모까지 원래 문서와 똑같이 돌아온다.
2. **본문 글자**: 한컴 PDF에서 나온 본문은 보통 멀쩡하다. 글자 대응표(ToUnicode)가 깨진 글자(옛한글 `U+F000` 등)는 한글 원문과 맞춰 대응표를 고친다.
3. **수식**: 한컴 PDF의 수식은 HancomEQN 글꼴의 사용자 영역 문자(`` 등)로 들어가서 복사하면 깨지고, 문장에서도 떨어져 나간다. 이 도구는
   - 수식마다 표식 색을 입혀 한 번 더 내보낸 뒤, 두 PDF를 비교해서 어느 그리기 연산이 몇 번 수식인지 정확히 찾는다.
   - 수식 글자는 그 글꼴의 윤곽선을 꺼내 똑같은 벡터 도형으로 바꾼다. 그래서 모양은 같고 글자로는 잡히지 않는다.
   - 수식 자리에 보이지 않는 글자(Tr 3)로 수식 글을 넣는다. 스트림에서도 그 자리에 넣고 기준선을 같은 줄 본문에 맞춰서, 긁으면 `전구가 원점 O이고 벽은 z = h인 평면` 처럼 문장 속 제자리에 나온다.
4. **검사**: 변환할 때마다 한컴 PDF와 그림을 비교하고(다른 화소 비율), MuPDF와 PDFium(크롬·엣지·웨일 엔진)으로 글자를 뽑아 깨진 글자 수와 수식 글이 나오는지 센다. 첨부 원본의 SHA-256도 확인한다.

## 알아 둘 것
- **첨부된 원본은 누구나 꺼낼 수 있다.** 한글 파일에 든 메모, 숨은 글, 변경 내용도 같이 간다. 받는 사람이 원본을 보면 안 되면 `--no-embed`로 만든다. 그러면 복구는 안 되고 글·수식 복사만 된다.
- 수식을 복사하면 한 줄 글로 나온다. 한글에 붙여 넣어도 수식 개체가 되지는 않는다. 수식 개체가 필요하면 PDF를 한글로 복구하면 된다.
- 옛한글은 MuPDF·Acrobat에서는 바로 나오지만, PDFium(크롬·엣지)은 겹쳐 그린 자모를 좌표순으로 다시 늘어놓아 순서가 바뀔 수 있다.
- 한컴 PDF는 XMP에 PDF/A-1b라고 적는다. 첨부 파일은 PDF/A-3에서만 허용되므로 표기를 3b로 바꾼다. 공식 검증기로 확인하지는 않았다.
- 줄 끝에서 나뉜 낱말은 PDF에서 긁으면 줄바꿈이 끼어 나온다. 이것은 PDF 자체의 성질이다.
- 한글 프로그램(COM)과 파이썬 패키지 `pyhwpx pikepdf pymupdf fonttools`가 필요하다. 검사에는 `pypdfium2`도 쓴다(없으면 그 검사만 건너뜀).

## 파일
- `hwp2pdf.py`: 변환 본체. `pdf2hwp.py`: 복구.
- `hwppdf/hwpexport.py`: 한글로 원본 PDF와 표식 PDF를 내보낸다(문서는 저장하지 않고 닫음).
- `hwppdf/pdfrewrite.py`: 쪽 내용 다시 쓰기(수식 → 도형 + 보이지 않는 글자, 투명 글꼴).
- `hwppdf/eqtext.py`: 한글 수식 스크립트 → 유니코드 한 줄 / LaTeX.
- `hwppdf/textfix.py`: 깨진 글자 대응표 고치기. `hwppdf/embed.py`: 원본 첨부·꺼내기. `hwppdf/verify.py`: 검사.
