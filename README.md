# hwp2pdf-safe

한글(.hwp/.hwpx) 문서를 PDF로 바꾼다. 만든 PDF는

- 원본 한글 파일로 되살릴 수 있다.
- 본문을 긁어 복사해도 글자가 깨지지 않고 줄바꿈도 빠지지 않는다(한컴 PDF는 크롬·엣지에서 문단 끝이나 표 행의 엔터가 빠진다).
- 수식을 긁으면 `x = (-b±√(b²-4ac))/(2a)`처럼 읽을 수 있는 글로 복사된다. 모양은 한컴 PDF와 같다.

## 설치
- Windows와 한글 프로그램(한글 2024에서 시험함)이 있어야 한다. PDF → 한글 되살리기는 한글 없이도 된다.
- `hwp2pdf-safe-setup-<버전>.exe`를 실행해 설치한다. 관리자 권한은 필요 없다(사용자 폴더에 설치).
- 바탕화면·시작 메뉴 바로가기와, 파일 우클릭 → **보내기** 메뉴가 생긴다.
- 지울 때는 Windows 설정 → 앱 → '한글 PDF 변환기'에서 제거한다.

## 쓰는 법
1. '한글 PDF 변환기'를 열고 파일을 창에 끌어다 놓는다(파일 추가·폴더 추가 버튼도 있음). 여러 개를 한 번에 넣을 수 있다.
   - 한글 파일은 PDF로 바뀐다.
   - 이 도구로 만든 PDF는 원본 한글 파일로 되살린다.
2. 설정을 고른다.
   - **원본 한글 파일을 PDF에 넣기**: 끄면 한글로 되살릴 수 없다.
   - **수식을 긁어 복사하면**: 읽기 쉬운 글 / LaTeX / 한글 수식 스크립트 / 복사 안 되게(모양만).
   - 저장 위치, 같은 이름이 있을 때(새 이름 또는 덮어쓰기), 다 되면 열기, 결과 검사하기.
3. **변환 시작**을 누른다. 결과 칸을 두 번 누르면 파일이 열린다.

설정은 다음에 열 때도 그대로 남는다.

## 꼭 알아 둘 것
- **PDF 안에 원본 한글 파일이 첨부된다.** PDF를 받은 사람은 누구나 첨부 파일을 꺼낼 수 있다. 메모, 숨은 글, 변경 내용도 같이 간다. 원본을 넘기면 안 되면 '원본 한글 파일을 PDF에 넣기'를 끈다. 그러면 한글로 되살리기는 안 되고 복사만 된다.
- 한글로 되살리기는 이 도구로 만든 PDF에서만 된다. 다른 PDF는 못 바꾼다.
- 수식은 한 줄 글로 복사된다. 한글에 붙여 넣어도 수식 개체가 되지는 않는다.
- 옛한글은 크롬·엣지에서 복사하면 자모 순서가 바뀔 수 있다.
- 변환하는 동안 한글 프로그램이 화면에 안 보이게 뜬다. 원본 파일은 고치지 않는다.
- 암호가 걸린 한글 문서는 변환하지 못한다.

## 직접 실행·빌드 (개발용)
```
pip install -r requirements.txt
python hwp2pdf_gui.py                       # 화면
python hwp2pdf.py 보고서.hwp [-o 결과.pdf] [--eq unicode|latex|hwp|none] [--no-embed] [--no-open]
python pdf2hwp.py 보고서.pdf [-o 폴더] [--no-open]
pip install pyinstaller && python build.py  # release\ 에 설치 파일 생성
```
